¿Cómo conectar una hoja de Google Sheets gratis en 2 minutos?
1. Creá una hoja en Google Sheets y andá a Extensiones → Apps Script.
2. Pegá este código corto y tocá Implementar → Nueva implementación → Aplicación web (Acceso: Cualquier persona):
function doGet(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var rows = sheet.getDataRange().getValues(); return ContentService.createTextOutput(JSON.stringify(rows.slice(1))) .setMimeType(ContentService.MimeType.JSON); } function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var d = JSON.parse(e.postData.contents); sheet.appendRow([new Date(), d.name, d.rel, d.choice, d.msg]); return ContentService.createTextOutput(JSON.stringify({ok:true})) .setMimeType(ContentService.MimeType.JSON); }
3. Copiá la URL que te da Google y pegala arriba. ¡Todos los votos de cualquier celular se verán en vivo!
